Cara menghubungkan ke Google Drive
  1. Buka script.google.com, buat proyek baru, lalu tempel isi file drive-endpoint.gs.
  2. Isi ROOT_FOLDER_ID (ID folder induk kontrak di Drive) dan TOKEN (kode rahasia bebas). Jalankan fungsi buildIndex sekali dan setujui izin aksesnya.
  3. Pilih Deploy, New deployment, jenis Web app. Isi Execute as: Me dan Who has access: Anyone. Salin URL yang berakhiran /exec.
  4. Di file index.html, cari DRIVE_CONFIG, isi endpoint dengan URL tadi dan token dengan kode rahasia yang sama. Simpan, lalu muat ulang halaman.

Supaya file terhubung ke pegawai, nama file atau nama foldernya harus memuat nama lengkap pegawai, atau NPP (PTT Reguler) atau nomor kontrak (PTT Project). Contoh: PKWT_Agil Sekar Aryani_2026.pdf atau Kontrak/Agil Sekar Aryani/PKWT 2026.pdf.
